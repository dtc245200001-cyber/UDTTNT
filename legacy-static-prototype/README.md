# Bản Demo HTML Tĩnh (Legacy Static Prototype)

Thư mục này lưu trữ các file giao diện tĩnh (HTML/CSS/JS) được xây dựng ở giai đoạn đầu của dự án trước khi chuyển đổi toàn diện sang kiến trúc hiện đại **React (Vite) + Supabase + FastAPI (AI RAG)**.

Các file trong thư mục này:
- `dashboard.html`
- `login.html`
- `register.html`
- `assets/css/auth.css`
- `assets/js/auth.js`

> **Lưu ý:** Các file này **không còn được sử dụng trong ứng dụng chính** và chỉ được lưu trữ nhằm phục vụ mục đích tham khảo lịch sử phát triển hoặc tài liệu báo cáo đồ án.
